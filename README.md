# 🔍 Blind Text Typer

A memory and typing practice game built with **pure HTML, CSS, and Vanilla JavaScript**. No frameworks. No libraries.

## 🎯 Project Goal

Train your short-term memory by remembering and typing sentences after they disappear.

## 🕹️ How to Play

1. Click **Start Game**
2. Read the sentence carefully
3. Sentence disappears after **5 seconds**
4. Type what you remember
5. Click **Check Answer**
6. Get +1 point for correct answers
7. Use **Reset Score** to start over

## 🛠️ Technologies Used

- HTML5
- CSS3 (custom styling, no frameworks)
- Vanilla JavaScript (DOM manipulation, setTimeout, event listeners)

## ✨ Features

- ✅ 12 unique sentences (randomly selected)
- ✅ 5-second memory timer
- ✅ Score tracking system
- ✅ Reset score button
- ✅ Wrong answer feedback (shows correct sentence)
- ✅ Clean light mode UI (black/grey/white)
